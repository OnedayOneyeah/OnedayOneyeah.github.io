# Project illustrations

Created with the built-in `image_gen` tool for the four research projects. These are conceptual illustrations, not institutional logos or photographs of project results.

Final assets are 1200 × 800 JPEG images compatible with the existing Jekyll responsive-image pipeline under `assets/img/projects/`.

## Final prompts

### on-device-training.jpg

Use case: stylized-concept. Asset type: landscape thumbnail for an academic research portfolio, 3:2 aspect ratio. Primary request: A smartphone beside a small microprocessor, with a compact neural network and a circular learning feedback loop, suggesting efficient on-device training and training-aware emulation. Blue and teal accent. Style: refined minimal editorial 3D illustration, matte materials, soft shadows, off-white background, sparse composition, consistent visual series, objects centered with generous margins, legible at card thumbnail size. No text, no words, no logos, no watermark. Standalone single illustration.
